# AgriGuard AI

AI Crop Health, Disease Detection, Smart Farm Management & Voice AI Agriculture Assistant Platform.

## Overview
AgriGuard AI is a comprehensive platform helping farmers manage farms, track crop health, detect diseases via AI, and interact through a Voice AI Agriculture Assistant.

## Architecture
The platform is organized as a scalable monorepo encompassing Next.js frontends, FastAPI backends, PostgreSQL database schemas, PyTorch/TensorFlow ML pipelines, and various supporting services.

Please see the `docs/` folder for architecture details, deployment strategies, and testing instructions.
