# Team Split

This project is built by a two-person engineering team.

## Person 1: AI + Backend + Database + Infrastructure
**Responsibilities:**
- FastAPI Backend Architecture
- PostgreSQL Database schemas and migrations
- Authentication & Authorization APIs
- Farm, Field, Crop, and Disease APIs
- AI Services (Computer Vision, ML Pipeline)
- Voice AI Backend (Speech processing, intents)
- Weather & Notification services
- Background jobs & CI/CD infrastructure
- Security implementation

## Person 2: Frontend + User Experience + Portals
**Responsibilities:**
- Next.js / TypeScript Frontends
- Farmer App & Dashboard
- Farm/Field/Crop UI
- Image Upload and AI Results UI
- Voice Interface and Assistant UI
- Expert Portal & Admin Portal
- Data visualization and analytics UI
- E2E testing and responsive accessibility

## Shared Collaboration
- API Integrations
- Integration Testing
- Architecture & Code Reviews
- Security & Release Engineering
